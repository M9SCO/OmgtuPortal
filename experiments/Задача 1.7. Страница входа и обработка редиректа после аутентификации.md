**Агент:**

Готово. Вот что сделано:

**Новые/изменённые файлы:**

1. **`.frontend/src/auth.ts`** — модуль авторизации:
   - Инициализирует `keycloak-js` с `onLoad: 'login-required'` → при открытии страницы сразу редирект на Keycloak
   - Автоматически обновляет токен каждые 10 сек
   - Экспортирует `getToken()`, `logout()`, `keycloak`

2. **`.frontend/src/main.ts`** — сначала проходит аутентификация, только потом монтируется Vue-приложение

3. **`.frontend/src/App.vue`** — после логина запрашивает `/api/me` с Bearer-токеном и показывает профиль + кнопку Logout

4. **`.frontend/vite.config.ts`** — проксирует `/api` на бэкенд (`http://localhost:5000`)

**Как работает:**
1. Пользователь открывает `http://localhost:5173`
2. `keycloak-js` видит что нет сессии → редирект на `http://localhost:8080/realms/upomgtu/protocol/openid-connect/auth`
3. После логина в Keycloak → редирект обратно с токеном
4. Фронт монтирует приложение и делает запрос `/api/me` с JWT-токеном
5. Бэкенд валидирует токен и возвращает данные пользователя

**Для кастомизации** (опционально) можно создать `.frontend/.env`:
```
VITE_KEYCLOAK_URL=http://localhost:8080
VITE_KEYCLOAK_REALM=upomgtu
VITE_KEYCLOAK_CLIENT_ID=upomgtu
```
