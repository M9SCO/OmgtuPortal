**`.env.example`** — шаблон с переменными:
- `DATABASE_URL` — строка подключения к БД
- `JWT_SECRET` — секрет для JWT (минимум 32 символа)

**`AppSettings.cs`** — типизированный класс с `[Required]` атрибутами. Метод `FromEnvironment()` читает переменные окружения и кидает `InvalidOperationException` с конкретным именем отсутствующей переменной.

**`Program.cs`** — `DotEnv.Load()` загружает `.env`, затем `AppSettings.FromEnvironment()` валидирует и создаёт экземпляр, зарегистрированный как `AddSingleton(appSettings)`.

Для использования в сервисах — инжектишь `AppSettings` через конструктор:
```csharp
public class MyService(AppSettings settings)
{
    // settings.DatabaseUrl, settings.JwtSecret, ...
}
```

Скопируй `.env.example` → `.env` и заполни реальными значениями для запуска.
